I build the parts of a product people actually touch — component architecture, state, animation, and the
last 10% of polish that separates *shipped* from *good*. Backend when it's the fastest path to a working
feature: APIs, auth, data modeling, deploys.

text, image, video, and 3D models in one place for architectural ideation — heavy real-time UI, lots of
state, no room for jank.
